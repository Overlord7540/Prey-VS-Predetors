Hard rules

  • Moves sequential · adjacent only
  • Predators attack from next tile — never stack on prey

Prey FSM

NORMAL→ PANIC→ DESPAIR→ NORMAL if predator > 3
NORMAL
Shared flock food goal · A* · eat underfoot if safe
PANIC
Flee + still prefer food (fcost)
DESPAIR
Flee + regroup flock · no food term

Despair triggers on kill · Panic scoring implemented · spotting trigger = Phase 2 wire

Fcost ≠ A*’s f

What it is

Local rank score over ≤8 neighbors (+ stay)

best gets N … worst gets 1
fcost = sum of ranks

Formulas

Panic: away from predator + toward food

Despair: away from predator + toward mate (unless already ≤2)

A* = global path to a goal  ·  Fcost = one emergency step under fear
